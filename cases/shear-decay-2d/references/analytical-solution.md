# 二维层流速度扩散解析解

不可压缩牛顿流体，速度 U=(u(y,t),0,0)，无外力、无压力梯度；x 周期，y=0,H 为静止无滑移壁面。对流项 U·grad(U)=0，动量方程为：

```text
du/dt = nu*d²u/dy²
u(0,t) = u(H,t) = 0
u(y,0) = A*sin(pi*y/H)
u(y,t) = A*sin(pi*y/H)*exp(-nu*(pi/H)^2*t)  # Equation 1
```

解析函数对时间求导和对 y 二阶求导得到相同的衰减系数，且满足初始、壁面条件。坐标用 m，时间用 s，nu 用 m²/s，A 和速度用 m/s；参数范围 nu>0、H>0，层流假设下成立。

本例网格高度 H=0.1 m，初始幅值 A=0.1 m/s，nu=0.001 m²/s。归一化尺度为 A，作为物理尺度而非验收阈值。速度各分量及模长逐时刻、逐单元中心比较；均值与均方根使用单元体积权重。不同单元中心的有限体积数值与点值解析解的差异如实报告，不据此自动判断通过或收敛。

此参考为上述方程的直接推导，不含测量不确定度。更改公式或参数时增加案例 revision，历史产物不覆盖。
