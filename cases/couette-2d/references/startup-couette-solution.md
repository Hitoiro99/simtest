# 二维启动 Couette 流解析解

## 物理问题

两块无限平行平板间距为 \(H\)。流体在 \(t=0\) 前静止；从 \(t=0\) 开始，下壁 \(y=0\) 保持静止，上壁 \(y=H\) 以恒定速度 \(U\) 沿 \(x\) 方向运动。流体不可压、牛顿、层流且无流向压力梯度，运动黏度为 \(\nu\)。因此 \(v=w=0\)，运动压力取零参考值。

## 速度解析解

对 \(0<y<H\)、\(t>0\)，启动 Couette 流的流向速度为

\[
\frac{u(y,t)}{U}
=\frac{y}{H}
+\frac{2}{\pi}\sum_{n=1}^{\infty}
\frac{(-1)^n}{n}
\sin\left(\frac{n\pi y}{H}\right)
\exp\left(-\frac{n^2\pi^2\nu t}{H^2}\right).
\tag{1}
\]

本工况采用 \(H=1\ \mathrm{m}\)、\(U=1\ \mathrm{m/s}\)、\(\nu=0.1\ \mathrm{m^2/s}\)，所以 \(Re=UH/\nu=10\)。受限表达式显式保留前六项，并使用

\[
k=\pi/H,\qquad b=\pi^2\nu/H^2
\]

减少表达式复杂度。第一个非零保存时刻为 1 s；在 \(t\geq1\ \mathrm{s}\) 时，首个舍弃项给出的速度绝对误差上界小于 \(10^{-21}\ \mathrm{m/s}\)，远低于双精度舍入和离散误差。

上壁突然启动使 \(t=0,y=H\) 存在初边值不相容。标准化场只包含内部单元中心，并在 \(t=0\) 应为静止初值。工况表达式使用 `min(1, t/first_output_time)`，其中 `first_output_time=1 s`，使 \(t=0\) 精确返回零；全部非零保存时刻均不小于首个非零输出时间，选择因子为 1，恢复式（1）的六项近似。该因子只处理实际采样集合中的 \(t=0\) 特值，不表示上壁线性升速，也不用于描述 0–1 s 之间未保存的连续时间解；模板中的上壁从 \(t=0^+\) 起始终保持 \(U\)。

## 压力参考

无外加压力梯度并固定参考单元压力时，运动压力参考为

\[
p(y,t)=0.
\tag{2}
\]

这里的 `p` 是 OpenFOAM 不可压求解器使用的运动压力，单位为 \(\mathrm{m^2/s^2}\)，不是以 Pa 表示的静压力。

## 适用范围与数值比较

解析式假定二维、层流、常物性、无限平板和无流向压力梯度。本案例用流向周期边界近似无限平板。平台在每个实际输出时刻和每个内部单元中心计算参考值，并按体积加权给出最大、平均和 RMS 绝对误差及归一化误差；不设置容差，也不自动判定收敛或通过失败。
