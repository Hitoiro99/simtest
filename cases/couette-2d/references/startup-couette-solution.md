# 二维稳态 Couette 流解析解

## 物理问题

两块无限平行平板间距为 \(H\)。下壁 \(y=0\) 静止，上壁 \(y=H\) 以恒定速度 \(U\) 沿 \(x\) 方向运动。流体不可压、牛顿、层流，无流向压力梯度，运动黏度为 \(\nu\)。流动达到定常后 \(v=w=0\)。

## 速度解析解

\(0<y<H\)：

\[
u(y)=\frac{U}{H}y,\qquad v=w=0
\tag{1}
\]

本工况 \(H=0.01\ \mathrm{m}\)、\(U=1\ \mathrm{m/s}\)、\(\nu=10^{-3}\ \mathrm{m^2/s}\)，所以 \(Re=UH/\nu=10\)，且 \(u(y)=100y\)。

## 压力参考

无外加压力梯度并固定参考压力，运动压力为

\[
p=0
\tag{2}
\]

`p` 是 OpenFOAM 的运动压力，单位为 \(\mathrm{m^2/s^2}\)。

## 数值比较

平台在每个内部单元中心计算 \(u(y)\)，并分别比较速度的 x、y、z 分量和模长；压力参考为零。报告只量化偏差，不设置通过/失败阈值。
